htmpy

Write HTML in Python

Installation

htmpy requires Python 3.14 or newer. From your project's directory, add htmpy with uv:

uv add htmpy

Starting a new project? Create one with Python 3.14, then add htmpy:

uv init --python 3.14 my-project
cd my-project
uv add htmpy

uv creates the project's virtual environment and installs htmpy and its dependencies.

Getting Started

Create HTML by nesting Python objects. Pass child elements or text as positional arguments and HTML attributes as keyword arguments. Save this example as page.py:

import htmpy

page = htmpy.html(
    htmpy.head(htmpy.title("Hello")),
    htmpy.body(
        htmpy.h1("Hello, world!"),
        htmpy.p("Built with htmpy."),
    ),
    lang="en",
)

print(page)

Run it with uv to print the HTML, including the HTML5 doctype:

uv run page.py

To view the page in a browser, save the output to an HTML file and open it:

uv run page.py > index.html
