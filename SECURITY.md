# Reporting a vulnerability

To report a suspected security issue in htmlkit, email the maintainer using the **Email** contact on Gavin Wiggins’s [website](https://gavinw.me/). Do not open a public issue or pull request for an undisclosed vulnerability.

Include the htmlkit and Python versions, a minimal example using dummy data, and the impact you observed. Do not include credentials or private application data. Please coordinate public disclosure with the maintainer so users can get a fix or mitigation.
