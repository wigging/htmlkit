htmlkit

Write HTML in Python.

Build HTML pages with Python objects instead of templates. Use htmlkit for static websites or HTML responses in web apps.

View htmlkit on Github.

Go to another page in this example.

Installation

Requires Python 3.14 or newer.

uv add htmlkit

Example

from htmlkit import body, h1, head, html, p, title

page = html(
    head(title("Hello from Python")),
    body(
        h1("Hello from Python"),
        p("Built with htmlkit."),
    ),
    lang="en",
)

print(page)
